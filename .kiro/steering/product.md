# Product Overview

Integration Feasibility Study System - 複数AIエージェントの無料枠を連携させ、月額$5未満の厳格なコスト制約で高品質な統合調査を実現するシステム。

## Core Capabilities

- **多次元統合評価**: REST/GraphQL/WebHook等の連携方式を、パフォーマンス・セキュリティ・コスト・リスクの4軸で包括的に評価
- **無料枠ローテーション**: 複数AIエージェント（Claude Code Pro、Gemini CLI、Windsurf、AWS Q Developer等）のクォータを相互補完し、単一エージェントの限界を克服
- **標準化されたレポート生成**: OpenAPI 3.1.x仕様 + Markdownレポートで機械可読かつ人間可読な調査結果を出力
- **コスト効率ベンチマーク（CEB）維持**: 無料枠を最大限活用しながら、品質を犠牲にせず98点のCEBスコアを達成

## Target Use Cases

### Primary Scenarios
- **新規API連携の技術選定**: スタートアップや個人開発者が、限られた予算内で外部API/サービスとの連携方式を評価し、最適な技術を選択
- **レガシーシステムの連携リスク評価**: 既存システムと新規サービスの互換性、コスト、リスクを事前に調査し、移行判断を支援
- **複数AIエージェントの協調開発**: 有料エージェント（推論・設計）と無料エージェント（実装・検証）を役割分担させ、コスト効率的な開発フローを確立

### Rotation Trigger Examples
- Windsurf（月100プレミアムプロンプト）が80%消費 → Gemini CLI/Claude Codeへ自動シフト
- Gemini CLI（日次1,000リクエスト）上限到達 → AWS Q Developer/Hugging Face APIへオフロード
- 応答レイテンシ1.5秒超過 → 次の安定エージェントへ切り替え

## Value Proposition

### 無料枠連携による限界突破
単一エージェントでは、日次/月次クォータ枯渇、安定性の低さ（無料版70点）、単一モデルのバイアスといった制約がある。本システムは、複数エージェントを戦略的にローテーションさせることで、**コスト効率（月額$0-5）と品質（CEB 98点）を両立**する。

### 技術的実現可能性の早期検証
API連携の実装前に、パフォーマンス（JMeter）、セキュリティ（OWASP ZAP）、コスト（ROI計算）、リスク（互換性チェック）を自動評価し、設計段階での意思決定を支援。失敗コストを最小化。

### 標準化と拡張性
OpenAPI仕様による標準化、Modular Pipeline Architectureによる拡張性により、新規無料枠エージェント（例: 新規スタートアップのAIツール）を容易に追加可能。cc-sddフレームワークと同様の共通インターフェースを維持。
